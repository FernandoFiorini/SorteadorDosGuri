⚙️ Configurações

Desmarcado = full aleatório. Cada card do resultado sempre tem o botão de resortear; com esta opção marcada, o novo campeão também respeita a lista de já sorteados.
As configurações ficam salvas no navegador. Campeões nunca se repetem dentro do mesmo sorteio.

🧪 Listas predeterminadas

Marque uma ou mais pools para sortear só entre os campeões delas. Desmarque tudo para o sorteio normal.
⚠️ Pool ativa: o sorteio usa apenas os campeões das listas marcadas e ignora campeões excluídos, lista de já sorteados e rotação de lanes.
